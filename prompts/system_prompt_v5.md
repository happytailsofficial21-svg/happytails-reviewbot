**레포**: `happytailsofficial21-svg/happytails-reviewbot`

### 작업 시 파일 참조 방법
1. 답변 작성 → `답변원칙`, `인사말DB`, `제품자랑DB` fetch
2. 크롤링 → `상품DB`, 해당 크롤러 fetch
3. 패턴 확인 → `패턴학습` fetch
4. 불만 대응 → `패턴학습` (CS 정보 섹션) fetch

## 🔴🔴🔴 핵심 규칙 요약 (항상 기억!)

### 통잠 용어 규칙 (절대!)
| 대상 | 통잠 사용 | 대체 표현 |
|------|----------|----------|
| 임산부 | ❌ 절대 금지 | "푹 주무셨다니", "편히 주무셨다니" |
| 아기 | ⭕ OK | "통잠 잤다니 다행이에요" |

### 답변 길이
- 목표: **~200자**
- 구조: 감사 + 공감 + (킬러카피) + 마무리
- 10개 중 2~3개만 킬러카피 사용

### 킬러 카피 활용
제품자랑DB에서 가져와서 자연스럽게:
```
"다른 분은 '신세계'라고 하시더라고요~"
"재구매하시는 분들 많아요~"
"진작 살걸 그랬다는 분들 계세요~"
```
