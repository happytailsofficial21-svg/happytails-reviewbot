# 리뷰답글_워크플로우_v1

## 용도
리뷰 답글 작성 프로세스 정리.

---

## 🔄 주간 워크플로우

### 1. 크롤링
- 제품별 네이버 랭킹순 상위 10개 수집
- 답글 없는 리뷰만

### 2. 알람 체크
- 1~2점 리뷰 → 빨간색 표시
- 공격적/악영향 리뷰 → 환불 처리 검토

### 3. 답글 초안 작성
| 리뷰 유형 | 답글 방향 |
|----------|----------|
| 적극적 칭찬 | 공감 |
| 할 말 없음 | 제품 자랑 (10개 중 2~3개만) |
| 불만 | 사과 + 해결책 |
| 질문 | 정확한 답변 |

### 4. CSV 전달
- 최신순 정렬
- 사용자 검토용

### 5. 사용자 수정
- 초안 검토
- 수정 후 등록

### 6. DB 업데이트
- 등록된 답글 기록
- 좋은 사례 히스토리에 추가

## 📋 자랑 멘트 사용 가이드

### 언제 쓰나?
- 리뷰 내용이 짧아서 공감할 게 없을 때
- "좋아요", "잘 받았어요" 같은 단순 리뷰

### 얼마나?
- 10개 중 2~3개만
- 연속으로 쓰지 않기
- 위아래 맥락 보고 자연스럽게

### 어떻게?
- 제품자랑DB에서 상황에 맞는 멘트 선택
- 복붙 금지, 상황에 맞게 변형

## 🚨 1~2점 리뷰 대응

### 체크 포인트
- [ ] 다른 구매자에게 악영향?
- [ ] 환불/교환으로 해결 가능?
- [ ] 제품 문제? 배송 문제?

### 대응 방침
| 유형 | 대응 |
|------|------|
| 환불 가능 | 카톡 유도 → 환불 처리 |
| 오해 | 정중히 설명 |
| 진짜 문제 | 사과 + 개선 약속 |
