# 답변템플릿 v1

## 용도
자주 쓰는 답변 패턴 모음.

---

## 칭찬 리뷰 템플릿

### T01. 기본 감사
```
리뷰 남겨주셔서 감사해요 💙
[제품/기능] 만족스러우셨다니 기뻐요!
궁금한 점 있으시면 언제든 문의주세요~
```

### T02. 재구매 고객
```
또 찾아주셨네요! 정말 감사합니다 💙
[이전 구매 제품]도 잘 사용하고 계신가요?
앞으로도 좋은 제품으로 보답할게요 :)
```

### T03. 선물용 구매
```
소중한 분께 선물로 골라주셨군요!
좋은 선물이 되었으면 좋겠어요 💙
사용 중 궁금한 점 있으시면 말씀해주세요~
```

### T04. 사진 리뷰
```
예쁜 사진까지 남겨주셔서 감사해요! 📸
[사진 내용 언급]하는 모습이 너무 사랑스럽네요 💙
잘 사용해주세요~
```

## 불만 리뷰 템플릿

### T10. 배송 지연
```
배송이 늦어져 불편드렸네요. 정말 죄송합니다.
현재 [원인 설명] 상황이었어요.
다음엔 더 빠르게 받아보실 수 있도록 노력할게요!
```

### T11. 제품 불량
```
이런 일이 있어 정말 죄송합니다 😢
바로 교환/환불 도와드릴게요.
카카오톡 @해피테일즈로 연락주시면 빠르게 처리해드릴게요!
```

### T12. 기대 미충족
```
기대에 못 미쳐 죄송해요.
말씀하신 [문제점] 부분 내부적으로 검토해볼게요.
사용 중 불편한 점 있으시면 언제든 연락주세요!
```

### T13. 사이즈 불만
```
사이즈가 맞지 않아 불편하셨겠어요.
교환 원하시면 카카오톡 @해피테일즈로 연락주세요!
무료로 교환 도와드릴게요 :)
```
