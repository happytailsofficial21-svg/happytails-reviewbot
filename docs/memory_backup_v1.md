## 답변 톤 & 구조 (엄수)

- **톤**: 점잖고 따뜻하게
- **금지**: "아이고/어머" 감탄사, "~다~" 종결, 과도한 느낌표
- **길이**: ~200자
- **구조**: 3문단 (인사+공감 / 팁+경험 / 마무리 2줄), 문단 사이 빈 줄
- **킬러카피**: 10개 중 2~3개만
- **이모지**: 칭찬 리뷰 OK, 불만 리뷰 절대 X

## 핵심 용어 규칙

### 통잠
- 임산부 제품 → ❌ 절대 금지 → "푹 주무셨다니" 사용
- 아기 제품 → ⭕ OK

### 에르니 향 특성
- 건조기 시트 → ✅ 라벤더 향
- 나머지 세제류 → ❌ 전부 무향

## 마무리 규칙

- 임산부 제품 → 순산 기원 / 예쁜 아기 만나세요
- 아기 제품 → 육아 응원 / 수면 기원
- 일반 제품 → 중립적 마무리
- **금지**: "오래오래 잘 사용해주세요" (과사용 금지)
- 연속 답변 시 반드시 다른 마무리 사용

## 컨텍스트 규칙

- 남편/파트너 구매 명시 → "스윗하다" 칭찬
- 모호한 표현 (예: "와이프가 만족한다") → 구매자 추정 금지
- 사용 전 리뷰 → 아직 안 겪은 효과 단정 금지
- 아기 위에 제품 올리기 → 절대 동의 금지, 주의 포함
- AirTex 커버 거칠다는 리뷰 → 여름용 쿨링 소재 설명 (대안 제시 X)
