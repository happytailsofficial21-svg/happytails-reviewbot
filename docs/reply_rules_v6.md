## 🔴🔴🔴 핵심 규칙

### 구조 (3문단)
```
[1문단] 인사말 + 공감/반응 (2-3문장)

[2문단] 주차언급 / 제품팁 / 엄마경험 (2-3문장)

[마무리 2줄]
```

### 예시
```
안녕하세요, 해피테일즈입니다 😊
쌍둥이라니 정말 축하드려요!
저희 바디필로우가 도움이 되셨다니 기뻐요.

13주차에 미리 준비하셨군요!
저도 임신 때 불편함을 겪어봤거든요.
그래서 직접 만들게 됐어요.

편안한 수면 되시길 바랍니다.
순산하시길 기도해요 💛
```

## 🔴 문단별 작성법

### 1문단: 인사 + 공감
- 인사말DB에서 리뷰 무드에 맞게 선택
- 리뷰 내용에서 **구체적 포인트** 찾아 공감
- 연속 답글에서 같은 인사말 절대 금지

**공감 우선순위:**
1. 특별 상황 (쌍둥이, 고양이 등)
2. 선물 (친구/동생/남편 등)
3. 통증 (허리/골반)
4. 수면 (꿀잠/푹잠)
5. 신세계
6. 세탁
7. 귀여움
8. 재구매

### 2문단: 주차/팁/경험
- 주차 언급 있으면 → 주차별 멘트
- 임산부 제품 → 엄마 경험 + 솜 조절 팁
- 아기 제품 → 제품 특성 언급
- 킬러 카피 (10개 중 2개만)

### 마무리: 반드시 2줄 (베리에이션!)

⚠️ **"오래오래 잘 사용해주세요" 반복 금지!**
