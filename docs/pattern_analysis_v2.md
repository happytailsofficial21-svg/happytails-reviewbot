## ⭐ 좋은 답글 패턴 (2016-17 직접 작성)

### 특징
1. **짧고 자연스럽다** (100~150자)
2. **구체적 해결책** 바로 제시
3. **진심이 느껴짐** - 형식적이지 않음
4. **복붙 티 안 남** - 매번 다른 첫 문장
5. **브랜드 스토리 자연스럽게** 녹임

### 좋은 답글 예시

**칭찬 리뷰:**
```
구입해주셔서 감사합니다 고객님. 해피테일즈는 정말 꿀잠! 전도사입니다. 
임신의 고통을 조금이라도 덜어드렸다니 정말이지 저희는 너무 행복합니다 
해피테일즈와 함께 남은 임신기간 잘 보내시고 꼭 순산하셔서 건강한 아기와 만나시기를 바랍니다.
```
→ 자연스러움, 진심, 적당한 길이

**불만 리뷰 (폭 좁음):**
```
안녕하세요 고객님. 폭이 좁아서 불편하실경우를 위해 폭을 +7cm 늘린 커버를 
소량 구비하고있습니다. 고객님의 불편을 해소하기 위해 고객센터에서 연락드릴 수 있도록 
조치하겠습니다.
```
→ 해결책 바로 제시, 액션 약속

**불만 리뷰 (효과 못 느낌):**
```
고객님 솜을 조금 빼내셔서 배를 한쪽 기둥의 위로 살짝 걸쳐주세요. 
기적적인 300% 효과가 난답니다
```
→ 구체적 사용법 안내, 짧고 명확

**단순 리뷰 ("좋아요"):**
```
고객님! 해피테일즈를 선택해 주셔서 정말 감사합니다.
```
→ 1문장으로 충분

## ❌ 나쁜 답글 패턴 (2024-26 GPT 스타일)

### 문제점
1. **너무 김** (300자 이상)
2. **반복적 첫 문장** - "안녕하세요, 엄마 발명가 박혜정입니다 😊"
3. **과한 공감** - "얼마나 힘드셨을지...", "마음이 먼저 쓰였어요"
4. **이모지 과다** - 💛🙏✨🌿🌙🌷🤍
5. **구체성 부족** - 실제 해결책 없이 감정만

### 나쁜 답글 예시
```
안녕하세요, 엄마 발명가 박혜정입니다 😊

25주차에 접어들면서 정기검진 이후 누워 있는 시간이 많아져
잠자리까지 불편해지셨다는 이야기를 읽는데,
허리까지 좋지 않으셨다니 얼마나 힘드셨을지 마음이 먼저 쓰였어요.
그 와중에 육아선배 친구의 추천으로
해피테일즈 바디필로우를 믿고 선택해 주셔서 정말 고맙습니다 👶🧡
... (계속 500자 이상)
```
→ 첫 문장 고정, 너무 김, 이모지 과다

## 🔵 제품별 CS 정보

### 바디필로우 (임산부용)

| 불만 유형 | 대응 |
|----------|------|
| 폭 좁음/답답함 | 솜 빼기, +7cm 커버 안내 |
| 높이 낮음 | 배 올리는 용도라 낮게 설계됨 (태아 압박 방지) |
| 효과 못 느낌 | 솜 빼고 배를 기둥 위로 걸치기 |
| 뜨거움 | 여름용 커버 안내 |
| 만삭 아닌데 불편 | 만삭 다가올수록 편해짐 |

**핵심 사용법:**
- 솜 빼서 높이 조절
- 배를 한쪽 기둥 위로 살짝 걸치기
- 주수 늘어날수록 효과 증가

⚠️ **임산부 제품 주의**: "통잠" 표현 금지! → "푹 주무셨다니" 사용

---

### 코코테일즈 (통잠이불) - 아기용

| 불만 유형 | 대응 |
|----------|------|
| ~~비즈 넣기 어려움~~ | ✅ **개선 완료** (2026.01) - 아랫쪽 확 열리게 변경 |
| 아기가 답답해함 | 발걸이 빼기, 팔/다리 자유롭게 |
| 효과 없음 | 적응기간 3-4일, 폭 조절 |

**핵심 포인트:**
- 모로반사 핵심 = **상체** 안정감
- 다리 답답해하면 발걸이 빼도 됨
- 팔 빼고 사용 가능
- ⭐ 비즈백 넣기 개선됨 (아랫쪽 오픈 구조)

---

### 쿨리베어 (옆잠베개) - 아기용

| 불만 유형 | 대응 |
|----------|------|
| 솜 빼기 번거로움 | 지퍼 많으면 아기 피부 긁힘 → 의도적 |
| 열남 | 가제 손수건 받치면 열 방출 어려움 |
| 세탁 | 솜통 세탁 X (커버만), 메모리폼 손세탁만 |

**핵심 포인트:**
- 신생아(0~100일): 솜 반드시 빼기
- 목높이 1cm 설계 (영아 척추 보호)
- 3중 레이어 (겉메쉬, 속메쉬, 솜코어)

---

### 슬립빈 (스와들) - 아기용

| 불만 유형 | 대응 |
|----------|------|
| 다리 답답해함 | 팔/몸에 감싸 눌러주는 방식으로 활용 |
| 적응 못함 | 1주일 적응기간 필요 |
| 팔 나옴 | 반대로 입혀도 됨 (무게 뒤로) |

**핵심 포인트:**
- 모로반사 완전히 잡아주진 않음 (완화에 도움)
- 시원한 소재 → 기저귀만 입히고 재워도 됨
- 안전 설계 (질식사고 방지)

---

### 틴더버드 (아기크림) - 아기용

| 불만 유형 | 대응 |
|----------|------|
| 효과 없음 | 초기 2주에 1통 자주 덧바르기 → 이후 1달 1통 |
| 향 강함 | 천연 유래, 시간 지나면 은은해짐 |
| 건조함 | 수분감 제형 → 로션/오일 덧바르기 |

**사용법:**
- 성인 피부이슈: 4시간에 1번
- 아기: 2~3시간에 1번
- 5분이면 흡수

| 세탁세제 | ❌ 무향 | 공용 | 알러지프리 성분 |

| 식기세척기 세제 | ❌ 무향 | 아기 | 식첨등급 원료 |

**에르니 공통 특징:**
- 갈락소라이드 Free (합성 머스크 성분 배제)
- EWG 그린등급
- 식첨등급 원료

**⚠️ 향 관련 답변 주의:**
- 건조기 시트: "향이 강하시면 반으로 잘라 사용해보세요"
- 세탁세제/젖병세제: "무향이라 아기에게 안심이에요"
- **절대 혼동 금지!** 세탁세제에 향 있다고 하면 안 됨
