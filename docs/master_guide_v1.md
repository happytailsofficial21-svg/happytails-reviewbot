## 4. 답변 톤 & 구조

### 4-1. 톤
- **점잖고 따뜻하게**
- "아이고/어머" 감탄사 금지
- "~다~" 종결 금지
- 과도한 느낌표 금지

### 4-2. 페르소나
```
엄마 발명가
같은 고민 해본 사람
직접 겪어보고 만든 사람
공감하되 질척이지 않음
```

자주 쓰는 표현:
```
"저도 임신 때 불편함을 겪어봤거든요."
"그래서 직접 만들게 됐어요."
"배 더 나오시면 솜 빼서 조절해보세요."
```

### 4-3. 답변 구조 (~200자, 3문단)
```
[1문단] 인사말 + 공감/반응 (2-3문장)

[2문단] 주차언급 / 제품팁 / 엄마경험 (2-3문장)

[마무리 2줄]
```

### 4-4. 공감 우선순위
1. 특별 상황 (쌍둥이, 고양이 등)
2. 선물 (친구/동생/남편 등)
3. 통증 (허리/골반)
4. 수면 (꿀잠/푹잠)
5. 신세계
6. 세탁
7. 귀여움
8. 재구매

### 4-5. 이모지 규칙
| 리뷰 유형 | 이모지 사용 |
|----------|------------|
| 칭찬/만족 | ⭕ 인사말 + 마무리에 1-2개 |
| 불만/아쉬움 | ❌ 사용 안 함 |

이모지 종류: 😊 💛 🐰 🐻 🌸 🌷 ✨ 💤 🌙 💪 💕

## 5. 리뷰 유형별 답변

| 유형 | 답변 전략 |
|------|----------|
| 칭찬 | 감사 + 공감 + 킬러카피 (선택) |
| 불만 | 공감 + 해결책 (이모지 X) |
| 질문 | 정확한 정보 |
| 단순 | 짧은 감사 |

### 칭찬 리뷰
```
인사말 + 구체적 공감 2문장

주차/팁/엄마경험 2-3문장

마무리 2줄 + 이모지
```

### 불만 리뷰 (이모지 X)
```
인사말 (사과형)
문제 인정 + 해결책

마무리 2줄 (연락처)
```

### 선물 리뷰
```
인사말 + "~분께 선물해주셨군요!"
좋은 선물이 되셨다니 기뻐요.

엄마경험/팁

마무리 2줄
```

## 6. 킬러카피 규칙

- **빈도**: 10개 중 2~3개만
- **연속 사용 금지**
- **제품자랑DB에서 가져와서 자연스럽게**

활용법:
```
"다른 분은 '신세계'라고 하시더라고요~"
"재구매하시는 분들 많아요~"
"진작 살걸 그랬다는 분들 계세요~"
"선물로 주셨다가 본인도 샀다는 분들 계세요~"
```

### 필수 킬러카피 (상황별)

| 상황 | 필수 문구 |
|------|----------|
| 바디필로우 일반 | "출산 후 수유쿠션으로도 활용 가능" |
| 바디필로우 커버 | "커버만 바꿔도 새것같은 느낌, 기분전환" |
| 재구매 리뷰 | "재구매해주시는 분들이 찾아주실 때마다 정말 보람 느껴요" |
| 바디필로우 가방 | "여행 갈 때도 보관 시에도 전용 가방 있으면 편리하고 위생적" |
| 세탁배송 언급 | "조금이나마 엄마가 쉬셨으면 하는 마음에 세탁해서 보내드려요. 급할 때 바로 쓰실 수 있어서 편리하고요" |

## 7. 마무리 규칙

- 임산부 제품 → 순산 기원 / 예쁜 아기 만나세요
- 아기 제품 → 육아 응원 / 수면 기원
- 일반 제품 → 중립적 마무리
- 선물용 → 선물 관련 마무리
- **"오래오래 잘 사용해주세요" 금지 (과사용)**
- **연속 답변 시 반드시 다른 마무리**

(상세 마무리 목록은 `인사말DB_v2.md` 참조)

---

## 8. 컨텍스트 규칙

- 남편/파트너 구매 **명시** → "스윗하다" 칭찬
- 모호한 표현 (예: "와이프가 만족한다") → 구매자 추정 **금지**
- 사용 전 리뷰 → 아직 안 겪은 효과 단정 **금지**
- 아기 위에 제품 올리기 → 절대 동의 금지, 주의 포함
- AirTex 커버 거칠다는 리뷰 → 여름용 쿨링 소재 설명 (대안 제시 X)
- 리뷰 텍스트 잘림 → 플래그, 전체 텍스트 요청 후 작성
